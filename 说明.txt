小班微上

【开始游戏】
进场前输入 1–16 个字符的昵称并选择职业。峡谷和榜单会同时显示昵称和职业。
· 单机练习：双击 index.html，或打开 GitHub Pages 版本，与九名 AI 进行 5 对 5。
· GitHub Pages 托管单机网页，联机房间需要另外运行 Node.js 服务。
· 联机开房：主机双击「启动.command」，或在目录里运行 npm ci 后运行 npm start。主机需 Node.js 18 或更新版本。
· 局域网的玩家打开启动窗口里的局域网地址，主机保持窗口运行。跨网络游玩需要把服务部署到公网可访问的主机。默认端口为 8899，可用 PORT 修改。
· 房间最多 10 人同场，第 11 人起按顺序排队观战，有空位时自动进场。

【晶石峡谷】
红蓝两队沿上、中、下三路推进，小兵定时出发。每队有三座防御塔，拆掉敌方三塔后才能伤害敌方水晶。摧毁水晶获胜。
英雄头顶显示五格血条。英雄倒下后会在基地复活，靠近己方基地可回血。
点击敌人会移动到攻击距离并自动普攻，点击地面取消锁定。滚轮缩放，小地图显示单位和建筑位置。

【按键】
方向键移动，也可以点击或拖动地面。动作也可点击画面下方的按钮。
Q 扇巴掌　W 语言攻击　E 踢腿　R 防御　D 跪拜
K 出拳　空格 跳跃
W 轮流触发 20 句语言攻击，例如「你这拳是走审批了吗？」和「别复盘了，直接删录像」。

【IDEA 界面】
按 F 切到网页内的 IDEA 风格 Java 工程。可切换和编辑示例文件，右侧终端会滚动显示对这些示例文件的检查结果。终端支持 check 和 clear。
按 Esc 或点「返回游戏」回到峡谷。切换界面时，联机房间继续运行。
